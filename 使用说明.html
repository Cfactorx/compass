一、30 秒快速上手

1打开页面 → 2允许定位 → 3授权传感器 → 4拿手机读盘
  1. 打开页面 → 浏览器提示定位时点「允许」（用来算当地磁偏角）
  2. 授权方向传感器 → 首次触摸罗盘盘面时弹出权限请求，点「允许」
  3. 拿着手机读盘 → 判读卡自动显示「坐什么山 · 什么向 · 吉凶」
💡 网页版无需安装，手机浏览器打开即可。建议加到主屏幕，下次一键直达。

模式用在哪需要什么

三、实地罗盘（现场测朝向）

3.1 怎么拿手机

┌──────────────┐ │ 手机平放 │ ← 屏幕朝上，水平端稳 │ 不要倾斜 │ └──────────────┘ ↑ 手机顶部指向 向方
  • 手机顶部指向的方向 = 向方，罗盘自动判出坐方（坐 = 向 + 180°）
  • 保持手机水平，倾斜会导致读数不准
  • 远离钢筋、电器、金属门框、汽车——磁场干扰会让罗盘乱摆

3.2 界面元素

元素位置说明
罗盘盘面中间大圆二十四山 / 分金格 / 八卦 / 龙脉层，随手机转动
盘面徽标盘面上方胶囊当前向方度数与所落分金
传感器状态条盘面下方绿点=已连传感器；黄点=相对方位模式；灰点=未检测到
判读卡状态条下方核心结果（见第五节）
手动转盘无传感器时才出现拖滑块手动输入向方度数
校准指南针卡片下方左按钮打开校准引导
保存记录卡片下方右按钮存进「测量记录」

3.3 罗盘乱摆 / 不准？先校准

点 「校准指南针」，按提示做：

  1. 手机拿稳，在空中画 8 字（或缓慢绕三圈）
  2. 远离金属、磁铁、电器、音响、车体
  3. 若提示「附近可能有磁场干扰」，换个位置再测

3.4 手机没有方向传感器？

系统会自动显示 「手动转盘」：

  • 拖滑块到已知的向方度数，判读照常出结果
  • 或改用「地图量测」模式（不需要传感器）

3.5 iPhone 用户注意

iOS 需要先触摸一下罗盘盘面才会弹权限请求（系统限制，必须由用户操作触发）。

  • 页面会显示橙色脉冲提示 📍 点此开启指南针权限 → 点它
  • 或者等 3 秒，权限弹窗会自动出现
  • 之前误点「不允许」：iPhone 设置 → Safari → 网站设置 → 动作与方向 改回允许，刷新页面

四、地图量测（地图上量坐向）

适合「没到现场，但知道位置」的场景——比如量一套房子、一块地的朝向。

4.1 三步测量

步骤操作
① 选「坐」点长按地图（约 0.35 秒）→ 出现红色「坐」圆点。长按瞬间有橙色光圈反馈
② 定「向」点拖动橙色圆手柄 → 两点间出现橙色虚线，箭头 ▶ 指向向方
③ 读结果下方判读卡自动显示坐山/向山/分金/吉凶
橙色虚线 + ▶ 箭头 表示「从坐指向向」，箭头方向就是向方。

4.2 地图工具

按钮功能
＋ / －缩放地图（右下角竖排）
◎定位到当前 GPS 位置
纬度 / 经度输入框手动输入坐标跳转（左下角）→ 点「跳转」
缩放建议：判读精度依赖两点实际距离。请放大到 ≥10 级再选点，否则两点可能相距好几公里，判读意义不大（系统会提示）。

4.3 坐标输入说明

  • 输入的是 GCJ-02（火星坐标，国内地图标准）
  • 如果手上是 GPS 原始经纬度（WGS-84），需自行换算
  • 纬度范围 -85~85，经度 -180~180

4.4 地图底图加载不出来？

网络不通或瓦片服务不可用时，自动切换成坐标网格——量测判读完全不受影响，只是看不到街道底图。

五、怎么读懂判读结果

5.1 结论行

坐子山午向 · 正向 [吉 · 旺] └─坐山 └─向山 └─兼向状态 └─吉凶标签

兼向状态有三种：

显示偏出中线含义
正向≤ 1.5°坐线在格正中，最理想
兼 N 分1.5° ~ 4.5°略微偏向相邻格
过重> 4.5°偏得太多，一般不建议

5.2 吉凶标签（颜色分级）

吉 · 旺可用 —— 旺 / 相 分金，孤虚旺相里的好格
凶 · 孤不利 —— 孤 / 虚 分金，普通凶格
⚠ 空亡 · 大空亡大凶 —— 骑在山界/卦界线上，最严重，必须避开
空亡用最重的视觉样式单独标出——它是玄学上最需要回避的情况，与普通「凶」有本质区别。

5.3 信息胶囊

胶囊内容
分金 xxx（旺/相/孤/虚）当前坐山所落的分金干支与属性
磁北 xxx° / 真北 xxx°两个参考系的向方度数（定位成功时同时显示）
⚠ 空亡提示命中空亡线时才出现
建议：xxx本山可用的旺相分金建议

5.4 专业参数面板

默认展开，包含：

  • 判读结论：完整一句话结论
  • 坐方度数 / 向方度数：精确到 0.01°
  • 偏出中线：偏了多少度 + 落在正向/兼向/过重哪个域
  • 分金格：干支 + 覆盖的度数区间 + 格宽（120 分金 3°格 / 240 分金 1.5°格）
  • 穿山龙（开启后）：所在龙 + 纳音 + 五行 + 吉凶
  • 透地龙（开启后）：同上
  • 磁偏角：当地磁偏角值 + 东偏/西偏 + 模型名
  • 真北换算：真北 = 磁北 ± 磁偏角
  • 判定依据：盘式与规则说明（地盘正针 · 三合盘）

六、设置项说明

点右上角 ⚙️ 进入。

设置选项怎么选
分金体系120 分金 / 240 分金 三合主流用 120（每山 5 格，3°）；要更细分用 240（每格 1.5°）
空亡判定宽度±0.5° / ±1° / ±1.5° 坐线距山界多少度内报警。默认 ±1.5°；要求严格就调小
坐标格式度 / 度分秒 影响顶栏坐标显示。日常用「度」
盘面风格现代 / 仿古 纯外观。仿古更接近实体罗盘的配色与字形
真北修正开 / 关 默认关（用磁北），与实体罗盘一致。见下方说明
穿山七十二龙开 / 关 开启后盘面多一圈「格龙层」，判读卡多加龙信息行
透地六十龙开 / 关 开启后多一圈「透地层」
⚠ 真北 / 磁北怎么选？
参考系说明适用
磁北（默认）磁罗盘实际指向与实体罗盘读数一致，实地对照用这个
真北地理正北与地图/卫星图/图纸对照，或要求真北体系判读时开启

开关打开后，盘面和判读卡会立刻刷新，不用晃动手机。

七、测量记录

点右上角 📜 进入。

  • 保存：实地罗盘 / 地图量测各有「保存记录」按钮
  • 内容：时间、模式、结论、坐山向山、分金、属性、坐方度数、当时的磁偏角
  • 上限：保留最近 50 条（超出自动淘汰最早的）
  • 删除：每条右侧「删除」按钮
V1.4 起「手工排盘」功能已合并到「地图量测」，旧记录会自动归到地图量测。

八、常见问题排查

Q：罗盘盘面不动 / 一直显示「尚未获取方向传感器数据」

按顺序排查：

  1. 权限没给（最常见）
    • Android：地址栏左侧 🔒 → 网站设置 → 运动与方向传感器 → 允许，然后刷新
    • iOS：iPhone 设置 → Safari → 动作与方向 → 打开
  2. 没触发权限请求：iOS 需先触摸罗盘盘面（点橙色脉冲提示），或等 3 秒自动弹窗
  3. 设备没有传感器：部分平板、老旧手机没有磁力计 → 用「手动转盘」或「地图量测」
  4. 浏览器不支持：换 Safari / Chrome。部分微信内置浏览器限制传感器，可点右上角「在浏览器打开」
Q：读数一直在跳 / 明显不准
  • 在校准：点「校准指南针」，画 8 字
  • 有磁场干扰：远离金属、电器、磁铁、车内、钢筋结构——最常见原因
  • 手机没放平：端稳，尽量水平
  • 状态显示「相对方位模式」：说明设备只提供相对角度（不是绝对方位），只能手动校零后参考。建议改用「地图量测」
  • 刚切回前台：从后台回来时读数会短暂重置，等一两秒稳定
Q：地图模式长按没反应
  • 长按要保持约 0.35 秒不动（手指移动超过 8px 会取消长按）
  • 看看是否已放大到合适级别
  • 键盘弹不出来时，直接点输入框即可（V1.6.1 起已修复触摸拦截）
Q：保存失败 / 记录丢失
  • 隐私模式：Safari 无痕模式无法保存，页面会提示「存储不可用，记录未保存（刷新即丢失）」。改用普通模式
  • 存储已满：清理一些旧记录
  • 记录存在本机浏览器里，不会上传，换浏览器/清缓存会丢
Q：地图底图一片空白

底图服务不可用时会自动降级为网格底图，量测功能完全正常。换网络或稍后重试可能恢复。
