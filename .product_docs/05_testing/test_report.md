## 4. 缺陷修复记录（开发期发现并已修复）

| 编号 | 级别 | 描述 | 修复 |
|------|------|------|------|
| BUG-001 | CRITICAL | WMM2025 系数表 n≥3 全部错值（早期嵌入旧版系数） | 从 COF 双源校验后重嵌，六城误差 0.0005° |
| BUG-002 | CRITICAL | Z 分量符号与 ψ 旋转方向错误致磁偏角偏差 ~0.1° | 对照 geomagnetism 包修正旋转公式 |

| BUG-004 | MINOR | 地图缩放按钮引用未暴露方法 + 事件冒泡误吞 | 新增 mapView.zoomBy + stopPropagation |
