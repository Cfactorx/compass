## 1. 产品定位与一句话描述

> **手机网页版专业风水罗盘**：实地测向 + 地图量测双模式，自动磁偏角修正，实时输出二十四山、120/240 分金、空亡骑线、孤虚旺相完整判读。

## 2. 信息架构

```
罗盘分金 H5（单页应用）
├── 顶部状态条：当前坐标 · 磁偏角 · 模式切换 Tab
├── 【Tab A】实地罗盘模式（默认）
│   ├── 罗盘盘面（随动）：天池红针 + 二十四山环 + 120分金环 + 度数环 + 十字天心
│   ├── 校准状态区：传感器精度指示 · 干扰提示 · 校准引导入口
│   └── 底部判读卡：专业参数 + 一句话结论 + 「锁定/记录」按钮
├── 【Tab B】地图量测模式
│   ├── 全屏地图：定位、搜索、长按选点、拖拽坐向线（起点=坐，终点=向）
│   └── 底部抽屉判读卡：同上 + 真北/磁北双方位角展示
├── 记录页（右上角入口）：历史测量列表 · 详情 · 删除
└── 设置页：分金体系(120/240) · 空亡判定宽度(±0.5°/±1°/±1.5°) · 坐标显示格式 · 关于
```

## 4. 功能详述与验收标准（AC）

### F01 实时罗盘盘面（P0）

**行为定义**：
- 盘面为 Canvas 绘制的同心环系（由内至外）：天池（磁针，红指北/指南传统式）、度数环（0–359，每 2° 刻度，每 30° 数字）、二十四山环（每山 15°，朱红字标 24 山名，四正山加重）、分金环（120 分金 3° 格，仅标注旺相干支：阳支山标丙X/庚X，阴支山标丁X/辛X，其余格灰显）。
- 盘面以「上=当前朝向」方式随动（盘转针不转的反向式：转动手机，盘面反向旋转，十字天心固定指向上方，十字线压住的度数即朝向）。
- 实时朝向 = 传感器磁北读数（webkitCompassHeading 或 deviceorientation 转换）；修正模式开关：传感器直读磁北（默认，罗盘体系本就是磁北）。
- 帧率目标 60fps，读数平滑（低通滤波，详见 TDD）。

**AC-LP**：
- AC01: 朝向真北（磁北）时，十字天心压 0°/360°，判读显示「子山」域。
- AC02: 传感器角度→盘面渲染角度的映射函数为纯函数，单测误差 ≤ 0.1°；真机人工抽检清单由 QA 出具（盘面无肉眼可见跳变）。
- AC03: 十字线当前压中的山、分金格在盘面上高亮（朱红描边 + 放大浮标）。
- AC04: 度数环数字与判读卡显示度数一致。

### F02 磁偏角自动修正（P0）

**行为定义**：
- 获取坐标（实地模式用 GPS；地图模式用地图选点坐标）后，本地 WMM 模型计算当前日期磁偏角 D（东偏为正）。
- 展示于顶部状态条：「磁偏角 -7.3°（西偏）· 模型 WMM」。
- 地图量测：真北方位角 T → 磁北方位角 M = T − D。
- 实地模式提供「真北修正」开关：开启后判读度数 = 磁北读数 + D（换算到真北体系），供需要真北体系的用户。
- 坐标不可用时显示「磁偏角未知（未定位）」，判读仍可用（按 D=0 并黄条提示）。

**AC-DEC**：
- AC05: 对北京（39.9°N,116.4°E）、广州（23.1°N,113.3°E）、哈尔滨、乌鲁木齐、上海 5 城，V1 计算结果与 NOAA 官方值偏差 ≤ 0.5°（QA 抽检）。
- AC06: 地图模式下，同一条坐向线，真北方位角与磁北方位角之差恒等于当地磁偏角，符号方向正确（东偏时磁北读数 < 真北读数）。

### F03/F04 二十四山与 120 分金判读（P0）

**行为定义**：
- 度数→山向映射采用标准三合盘地盘正针表（TDD 附全表），山界即 7.5° 的整数倍。
- 判读卡展示：朝向山 + 坐山（对宫）、距山中线偏角、所落分金格干支、该分金属性（旺/相/孤/虚/空亡）。
- 分金属性规则（默认，设置不可改）：天干丙、庚 → 旺；丁、辛 → 相（以上「旺相」可用）；甲、壬 → 孤；乙、癸 → 虚；戊、己 → 空亡。
- 结论话术示例：「坐子山午向 · 正向 · 分金庚子（旺相）—— 可用」；落孤虚空亡时：「分金戊子（空亡）—— 建议避开，可选丙子/庚子」。

**AC-MT**：
- AC07: 度数→二十四山换算，对 24 个山中线 ± 表格全量单测通过（含 0°/360° 环回边界）。
- AC08: 每山的 5 个分金格宽度均 3°，戊X 恒居本山中线 ±1.5°（地支山按全表核对）。
- AC09: 判读卡所示山向 = 盘面十字线所压山向，二者一致率 100%。
- AC10: 结论层必须同时包含：坐山、向山、正向/兼向、分金干支、属性、可用性建议，六要素齐全。

### F05/F06 地图选点量测（P0）

**行为定义**：
- 地图：自实现轻量瓦片地图（GCJ-02 腾讯栅格瓦片），支持拖动、双指缩放、双击放大、返回定位。
- 定位：调用浏览器 Geolocation 获取当前位置（GCJ-02 火星坐标由 WGS-84 转换，内嵌转换算法），地图飞至定位点。
- 选点：长按地图任意点弹出「以此点为坐山点」；坐向线终点默认为屏幕中心拖拽手柄，用户拖动终点画线。
- 量测输出：以坐点坐标计算磁偏角；终点→起点（向→坐）真北大圆方位角 T；磁北 M = T − D；按 M 判读向山、按 M+180° 判读坐山，输出完整判读卡（同 F03/F04 结构）+ 真北/磁北双度数 + 线段距离。
- 坐向线可吸附显示：线经过的山界以红点标记并告警（联动 F07）。

**AC-MAP**：
- AC11: 定位点地图显示位置与手机自带地图 App 定位偏差 ≤ 50m（GCJ-02 转换正确性）。
- AC12: 正北方向（终点在起点正北）拉线，真北方位角显示 0°（误差 ≤ 0.1°，短距离投影误差可忽略）。
- AC13: 拉线结果不依赖地图缩放级别（同一线段在任意 zoom 下判读结果不变）。
- AC14: 无定位权限时，地图仍可手动浏览选点量测（降级路径可用）。

### F07 兼向与空亡/骑线告警（P0）

**行为定义**：
- 正向：距本山中线 ≤ 1.5°（恰落本分金格）。
- 兼向：偏出中线 1.5°–4.5°，表述「X山兼Y山N分」（N = 偏出度数 / 1.5，四舍五入，最大三分；Y 为偏向侧相邻山）。
- 偏出 > 4.5°：仍属本山域则标「兼向过重」；判读按实际所落山输出。
- 骑线/空亡：朝向线距任一山界 ≤ 判定宽度（设置项，默认 ±1.5°）→ 弹朱红告警「压XX|XX山界（小空亡）」；若该界同时为八卦卦界（癸丑、寅甲、乙辰、巳丙、丁未、申庚、辛戌、亥壬）→「大空亡」。
- 告警同时高亮盘面（实地）或线上标记（地图）。

**AC-WARN**：
- AC15: 7.5°（子癸界，非卦界）±1.5° 内触发「小空亡」；22.5°（癸丑界，坎艮卦界）±1.5° 内触发「大空亡」。
- AC16: 3° 偏角（子山偏壬 3°）→「子山兼壬二分」；4.5°→「三分」。
- AC17: 判定宽度设为 ±0.5° 后，1° 偏界不再告警（设置生效）。

### F08 结论化输出（P0）

**行为定义**：
- 判读卡双层：上层大字结论（如「坐子向午 · 兼壬丙三分 · 庚子分金（旺相）✅ 可用」），下层可展开专业参数（各环读数、磁偏角、判定依据）。
- 通俗层文案规则：旺相→「可用」；孤/虚→「不可用（孤/虚）」；空亡/骑线→「大凶方位，避用」；兼向三分→附加「兼向偏重，谨慎」。
- **判读卡下方常驻免责小字**（实地/地图两模式一致）：「结果仅供参考，不构成任何决策建议」。

**AC-CONC**：
- AC18: 任意度数输入，结论六要素齐全且与专业层参数一致（结论由同一引擎生成，禁止两套口径）。

### F09 传感器校准与干扰提示（P1）

**行为定义**：
- 首次进入实地模式：全屏引导「请点击开启方向传感器」（iOS 权限）+「8 字校准动画」。
- 传感器精度事件（absolute/accuracy）低于阈值 → 顶部黄条「附近可能有磁场干扰，请远离金属/电器或重新校准」。
- 校准入口常驻判读卡角落。

**AC-CAL**：
- AC19: iOS Safari 首次进入必须经用户点击触发 requestPermission，授权/拒绝均有明确状态反馈；拒绝后引导切地图模式。
- AC20: 检测到 accuracy 为 uncalibrated 时 3 秒内出现黄条提示。

### F10 240 分金切换（P1）

**行为定义**：设置切换后，分金环重绘为 1.5° 格（240 分金，干支按六十甲子两轮排布表），判读输出「X山 · 分金格序号 + 干支」，空亡/旺相规则同表适用。默认关闭。

**AC-240**：AC21: 切换后同一度数的山向结论与 120 模式一致（山向不因分金粒度改变），仅分金粒度细化。

### F11 测量记录（P1）

**行为定义**：判读卡「记录」按钮保存：时间、模式、坐标、度数、完整结论 JSON；记录页列表查看、点击回看详情、左滑/长按删除；上限 50 条 FIFO。

**AC-REC**：AC22: 保存后刷新页面记录仍在；第 51 条覆盖第 1 条；删除即时生效。

### F12 设置（P1）

**行为定义**：分金体系（120/240）、空亡判定宽度（0.5°/1°/1.5°）、坐标格式（度/度分秒）、真北修正开关、盘面风格（P2：现代/仿古）。设置持久化 localStorage。

**AC-SET**：AC23: 修改任一设置后刷新页面配置保持并即时作用于判读引擎。

## 5. 关键用户路径

### 路径 1：实地测向（P1/P2 用户主路径，≤3 步）

```
打开 H5 → [首次：点击开启传感器 + 定位授权] → 端平手机对准朝向 → 读结论（自动刷新）
                                                     └→ 点「记录」保存
```

### 路径 2：地图远程量测（P1 从业者核心路径，≤4 步）

```
切到「地图」Tab → [定位 或 搜索/拖动/长按选点] → 拖动终点拉坐向线 → 读判读卡结论
```

### 路径 3：降级路径（无传感器/无定位）

```
地图 Tab → 手动浏览地图（无需定位权限）→ 长按选点 → 拉线 → 结论
```

## 6. 非功能需求

| 类别 | 需求 |
|------|------|
| 性能 | 首屏可交互 ≤ 3s（中端安卓，4G）；罗盘动画不掉帧（目标 60fps）；单文件体积 ≤ 500KB（不含瓦片） |
| 兼容 | iOS Safari 14+、微信内置浏览器（X5/WKWebview）、Android Chrome 90+；最低适配 360×640 视口 |
| 部署 | 纯静态单 HTML 文件（内联 CSS/JS），支持 file:// 直开（地图瓦片需联网）与任意静态托管 |
| 数据 | 无外传：坐标、记录仅存 localStorage；无统计埋点（V1） |
| 合规 | 底图为审图号合规腾讯瓦片；页面底部固定免责声明「结果仅供参考」 |
| 降级 | 瓦片加载失败时，地图自动降级为坐标网格底图，选点拉线量测功能不中断，顶部黄条提示「地图底图不可用」 |
| 离线 | 断网时可用地基罗盘功能（磁偏角用上次缓存或 0 值并提示），地图模式不可用需提示 |
