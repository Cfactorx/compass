## 1. 项目背景

### 1.1 业务背景

传统风水堪舆中，「分金」是定坐向的核心技术：罗盘将周天 360° 划分为二十四山（每山 15°），每山再细分——120 分金（每分金 3°）或 240 分金（每分金 1.5°），用于阴宅立碑、阳宅定向的精确坐向判定，并避开「空亡线」「骑线」等凶煞方位，取「旺相」分金。

当前痛点：

| 现状 | 问题 |
|------|------|
| 实体罗盘 | 价格数百至数千元、笨重难携、盘面密密麻麻，非专业者无法判读 |
| 手机自带指南针 | 只有 360° 方位角，无二十四山、无分金层，无空亡/旺相判读 |
| 市面风水罗盘 App | 多为原生 App，需下载安装；绝大多数**不做磁偏角修正**，更无地图坐标联动 |
| 在线地图（高德/百度/腾讯） | 能测方位角，但显示的是真北方位角，与罗盘磁北体系不一致，无法直接换算分金 |

### 1.2 关键洞察

**真北 vs 磁北的换算鸿沟是本产品的技术护城河**：

- 地图坐标（经纬度）测出的方位角基于**真北**（True North）；
- 传统罗盘测量基于**磁北**（Magnetic North）；
- 两者差值即**磁偏角**（Magnetic Declination），在中国境内约为 -11°（西偏）至 +10°（东偏）不等，且随地理位置与年份变化；
- 不做磁偏角修正，地图上量的「子山午向」到了实地用罗盘复核可能差出一整个山向。

因此，**「根据地图坐标定位分金」的本质**：以地图选点坐标为输入，实时计算当地磁偏角，将真北方位角体系精确换算为罗盘磁北体系，输出二十四山、分金、空亡、旺相等完整判读。

### 1.3 生态位

本项目与用户既有的「每日运程助手」产品线（桌面版 + 网页版）同属玄学工具生态，可共享用户群与视觉语言（浅色暖色系、桃橙主色 #EF7D2D）；V1 作为独立 H5 交付，预留后续入口整合。

## 2. 业务目标

| 编号 | 目标 | 衡量指标 |
|------|------|---------|
| G1 | 提供专业级分金判读能力 | 方位角→分金换算误差 0°（纯数学），磁偏角计算误差 ≤ 0.5° |
| G2 | 手机网页即开即用，零安装 | 首屏加载 ≤ 3s（中端机型 4G 网络）；核心操作 ≤ 3 步 |
| G3 | 双模式覆盖实地与远程场景 | 实地罗盘模式 + 地图量测模式均可用 |
| G4 | 降低专业门槛 | 非专业用户无需懂罗盘盘面，直接读结论（如「坐子山午向兼壬丙三分，分金丙子，旺相，吉」） |
| G5 | 合规与准确性 | 地图底图符合中国测绘法规（GCJ-02），罗盘体系遵循主流三合/三元盘通则 |

## 3. 目标用户

| 用户群 | 画像 | 核心诉求 |
|--------|------|---------|
| P1 风水从业者 | 专业堪舆师，精通盘面 | 快速复核、替代笨重实体罗盘；需要 120/240 分金、空亡线等专业层 |
| P2 玄学爱好者 | 对风水有基础认知的爱好者（与「每日运程助手」用户群高度重合） | 看房选墓时自助测向；需要通俗结论输出 |
| P3 大众用户 | 买房看朝向、清明祭祖立碑 | 简单易懂的吉凶提示，操作零门槛 |

**优先级**：P1、P2 为核心用户（功能完整度优先）；P3 受益于结论化输出（体验优先）。

## 4. 痛点与价值主张

### 4.1 痛点清单

| 编号 | 痛点 | 影响人群 | 现有方案缺陷 |
|------|------|---------|-------------|
| PP1 | 实地测向后，回家在地图上对不上方位 | P1/P2 | 无工具做真北↔磁北换算 |
| PP2 | 想远程（不去现场）预判某地块的分金可行性 | P1 | 只能凭经验估 |
| PP3 | 罗盘盘面读不懂，尤其分金层孤虚旺相 | P2/P3 | App 只给角度，不给结论 |
| PP4 | 手机罗盘受磁场干扰（车载、钢筋结构旁），读数漂移 | 全部 | 无干扰提示与校准引导 |
| PP5 | 骑线/空亡线（山与山交界 ±1.5°）落在凶位不自知 | P1/P2 | 普通指南针无此概念 |

### 4.2 价值主张

> **「地图点一点，分金全知道」**——把专业罗盘师的能力装进一个手机网页：
> 选点坐标 → 磁偏角自动修正 → 二十四山分金判读 → 吉凶结论一句话。

## 5. 业务范围

### 5.1 范围内（In Scope）— V1

1. **实地罗盘模式**：调用手机 DeviceOrientation API 实时指向，罗盘盘面（天池 + 二十四山 + 120 分金）随动，自动套用当前坐标的磁偏角修正。
2. **地图量测模式**：内置手机端地图（选点/搜索/长按拾取坐标），用户拉线确定坐向线，输出该线两端的山向、分金、兼向、空亡判定。
3. **磁偏角计算**：内嵌世界地磁模型（WMM）系数，前端本地计算任意坐标、当前日期的磁偏角，无需联网请求。
4. **分金判读引擎**：二十四山 ↔ 度数换算、120 分金（含孤虚旺相/空亡）、240 分金、兼向算法（兼左兼右、几分）、骑线/空亡线告警。
5. **结论化输出**：专业参数 + 一句话通俗结论双层展示。
6. **定位与坐标**：GPS/基站定位获取当前位置；坐标显示与手动输入（支持 WGS-84/GCJ-02 标注）。
7. **校准引导**：手机传感器校准动画引导（画 8 字）、磁场干扰强度提示。

### 5.2 范围外（Out of Scope）— V1 明确不做

| 项 | 原因 |
|----|------|
| 原生 App / 小程序 | 用户明确要求网页版（H5） |
| 后端服务与用户账号体系 | V1 纯前端静态部署，降低成本与合规复杂度 |
| 理气排盘（玄空飞星、三合水法等） | 超出「定位分金」边界，列入 V2 候选 |
| 自动寻找「最佳分金」推荐 | 涉及流派差异大，V1 只做判读不做建议 |
| 多语言 | 仅简体中文 |
| 历史记录云同步 | V1 用 localStorage 本地保存 |

### 5.3 边界判定原则

- 有争议的流派规则（如分金用 120 还是 240、空亡取 ±几度）：**设置项可切换**，默认采用主流三合派通则，并在界面注明依据。
- 磁偏角以 WMM 模型为准，不承诺与实测完全一致（地球磁场局部异常不可建模），误差提示 ≤ 0.5° 为模型精度。

## 6. 核心业务流程（概要）

```
用户打开 H5
    │
    ├─【模式A：实地罗盘】─→ 请求定位权限 ─→ 获取坐标 ─→ 计算磁偏角
    │        ─→ 传感器实时指向 ─→ 罗盘盘面随动 ─→ 实时判读山向/分金
    │
    └─【模式B：地图量测】─→ 打开地图 ─→ 选点/搜索/定位
             ─→ 拉坐向线（起点=坐，终点=向）─→ 计算真北方位角
             ─→ 坐标换算磁偏角 ─→ 输出磁北方位角 ─→ 分金判读报告
```

（详细用户路径与交互稿由 PRD 阶段定义）

## 7. 商业模式与部署

- **部署形态**：纯静态 H5（单页应用），支持静态托管与内网部署；与「每日运程助手」网页版同形态。
- **商业模式**：V1 免费工具，沉淀用户；后续可挂接既有产品生态（入口互换）。
- **合规要求**：
  - 地图底图必须使用审图号合规的中国地图服务（GCJ-02 坐标系）；
  - 页面底部标注「仅供参考，不构成任何决策建议」。

## 9. 风险与假设

| 编号 | 风险/假设 | 等级 | 应对 |
|------|----------|------|------|
| R1 | iOS Safari 的 DeviceOrientationEvent 需用户手势触发权限申请 | 高 | 首次进入弹层引导点击授权；被拒时引导用地图模式 |
| R2 | 微信内置浏览器传感器 API 受限 | 高 | 检测环境降级提示；地图模式为完整替代路径 |
| R3 | 安卓部分机型 deviceorientationabsolute 不可用，webkitCompassHeading 缺失 | 中 | 多 API 回退策略（TDD 详述） |
| R4 | 地图 JS SDK（腾讯/高德）密钥有域名/配额限制 | 中 | 优先无密钥方案（Leaflet + 合规瓦片）或用户自备 Key，TDD 决策 |
| R5 | 磁场局部异常导致实测偏差 | 低 | 界面明示模型精度；提供传感器强度指示 |
| A1 | 假设用户在中华人民共和国境内使用（地图合规与磁偏角范围） | - | 边界外使用仅保证罗盘数学正确，地图功能不承诺 |
| A2 | 假设 V1 无后端、无账号，数据均存本地 | - | 架构按纯静态设计 |
