## 3. 需求变更记录（验收确认）

1. **F05 地点搜索 → 手动输入经纬度**：免密钥约束下无地理编码能力，以「瓦片地图选点 + 手动输入坐标」双入口替代。影响：低（核心场景为现场量测）。
2. **TDD 坐向语义澄清**：向方 bearing = 坐点→向点（真北方位角），坐 = 向 + 180°，分金取坐山格；M = T − D（东偏为正）。与实现一致，文档已回写。
